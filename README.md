# 센바이블 CEN Bible PWA 업로드 파일

이 폴더 안의 파일을 GitHub Repository 루트에 그대로 업로드하세요.

필수 파일:
- index.html
- manifest.json
- service-worker.js
- icons 폴더 전체

GitHub Pages 설정:
1. Repository > Settings > Pages
2. Source: Deploy from a branch
3. Branch: main / root 선택
4. 배포 주소로 접속 후 Android Chrome에서 홈 화면에 추가

아이콘이 바로 안 바뀌면 기존 홈화면 아이콘을 삭제하고 Chrome 캐시를 지운 뒤 다시 추가하세요.
